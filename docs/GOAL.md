# 总目标（GOAL-001）

在不直接复用旧实现、不迁移旧数据的前提下，以 `docs/功能开发清单.xlsx` 中的一期和二期功能为范围，
完成一个可构建、可测试、可部署的协同办公平台。

## 技术目标

- 单 Maven、单 Spring Boot 后端。
- Vue3 + TypeScript PC 端。
- uni-app + Vue3 H5 端。
- 全新数据库结构。
- 权限、组织、流程、文件、消息和审计能力。
- 一期、二期完整交付。
- 自动化测试。
- 可部署交付。

## 三期

三期功能只保留在 Excel 中，不进入当前工作包。

## 不在范围

- 三期功能。
- 旧数据迁移。
- 真实第三方 SSO、短信、二维码登录、电子签章、WPS 中台。模拟适配器只用于自动验收，不代表已完成真实生产集成。
- 生产环境实际部署。
