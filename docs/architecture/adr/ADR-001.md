# ADR-001：JDK 与 Spring Boot 版本基线

## 状态

proposed

## 上下文

后端需要选择一个稳定的 JDK 和 Spring Boot 版本基线。版本选择会影响构建、部署、第三方库兼容性以及团队学习成本。当前任务阶段（S0）不立即冻结版本，但必须在 S1 门禁前完成决策。

## 考虑选项

- JDK 17 + Spring Boot 3.x（LTS，长期支持）
- JDK 21 + Spring Boot 3.x（最新 LTS，虚拟线程等特性）
- JDK 8 + Spring Boot 2.x（旧版本，已接近生命周期尾声）

## 决策

待定。本 ADR 在 S1 门禁前完成评审并确定最终版本。

## 后果

- 版本冻结前，架构文档和工程骨架保持版本无关。
- 版本确定后，所有后端代码和 CI 必须使用统一版本。
