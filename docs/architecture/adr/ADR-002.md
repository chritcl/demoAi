# ADR-002：业务包分层单体和包边界验证方案

## 状态

proposed

## 上下文

后端采用单 Maven 工程、单 Spring Boot 应用、业务包分层单体架构。需要自动化手段确保业务包边界不被破坏。

## 考虑选项

- ArchUnit（基于 JUnit 的架构测试）
- 自定义 Checkstyle/SpotBugs 规则
- 手动代码审查

## 决策

推荐采用 ArchUnit 进行自动化架构测试。具体规则在 `docs/architecture/BACKEND-ARCHITECTURE.md` 中定义。最终方案在 S1 门禁前确认。

## 后果

- 架构规则必须可自动验证。
- 任何违反包边界的行为都会导致构建失败。
