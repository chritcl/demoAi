# ADR-003：流程引擎选型

## 状态

proposed

## 上下文

综合办公（如用车、用印、出差、请休假等）需要工作流支持。需要决定是自研流程引擎还是采用第三方/开源流程引擎。

## 考虑选项

- Flowable（开源，功能成熟，社区活跃）
- Camunda（开源/商业，功能强大）
- 自研轻量级流程引擎（可控但成本高）
- 基于状态机的简单审批流（适合一期，扩展性有限）

## 决策

待定。必须在 S1 门禁前完成评审并确定选型。

## 后果

- 流程引擎选型直接影响 `s4_workflow` 业务包的设计。
- 跨业务包调用契约（如 `s3_office` → `s4_workflow`）需根据选型更新。
