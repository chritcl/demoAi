# ADR-004：认证与 Token 模型

## 状态

proposed

## 上下文

系统需要统一的认证与授权机制。PC 端、移动端和其他潜在客户端需要共享用户身份和权限。

## 考虑选项

- JWT + Redis 黑名单
- Session + Cookie
- OAuth 2.0 / OIDC 第三方集成
- 自定义 Token + 服务端存储

## 决策

待定。推荐在 S1 门禁前选择 JWT 或 Session 方案，并明确 Token 生命周期、刷新机制和退出策略。

## 后果

- 认证方案决定 `s0_xtsz` 业务包中用户/权限模块的实现。
- 影响 PC 端和移动端登录状态管理。
