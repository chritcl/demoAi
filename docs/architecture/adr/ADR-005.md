# ADR-005：数据库迁移与业务包数据所有权

## 状态

proposed

## 上下文

数据库结构可以重新设计，需要决定迁移工具和数据表 ownership 规则。

## 考虑选项

- Flyway（版本化迁移，Spring Boot 集成良好）
- Liquibase（XML/YAML 定义，支持回滚）
- 手写 SQL 脚本

## 决策

推荐采用 Flyway。每张表必须声明唯一 owner 业务包。具体规则在 `docs/architecture/DATA-ARCHITECTURE.md` 中定义。最终方案在 S1 门禁前确认。

## 后果

- 迁移脚本由 owner 业务包负责维护。
- 跨业务包外键默认禁止。
