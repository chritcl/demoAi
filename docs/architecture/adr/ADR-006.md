# ADR-006：API 契约与 OpenAPI 客户端生成

## 状态

proposed

## 上下文

后端与前端需要稳定的 API 契约。需要决定是否使用 OpenAPI 规范生成客户端代码或文档。

## 考虑选项

- SpringDoc + OpenAPI 文档，不生成客户端
- OpenAPI Generator 生成前端 TypeScript 客户端
- 手动维护 DTO 和前端类型

## 决策

待定。推荐在 S1 门禁前确认是否采用 OpenAPI 生成客户端，或仅作为文档工具。

## 后果

- 影响前后端接口协作方式。
- 影响 PC 端和移动端类型定义生成流程。
