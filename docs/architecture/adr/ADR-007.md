# ADR-007：文件存储抽象

## 状态

proposed

## 上下文

系统需要统一的文件上传、下载、存储和预览能力。文件可能存储在本地、MinIO、OSS 或其他对象存储中。

## 考虑选项

- 本地磁盘 + 路径映射
- MinIO（自托管 S3 兼容对象存储）
- 阿里云 / 腾讯云 OSS
- 抽象存储接口，支持多实现切换

## 决策

待定。推荐在 S1 门禁前确定是否引入抽象存储接口以及默认实现。

## 后果

- 影响 `s6_file` 业务包的设计。
- 影响文件预览和下载接口。
