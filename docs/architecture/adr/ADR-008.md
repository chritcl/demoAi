# ADR-008：PC 前端目录和状态管理

## 状态

proposed

## 上下文

PC 端采用 Vue3 + TypeScript。需要决定目录结构、状态管理方案和组件库。

## 考虑选项

- Pinia（Vue 官方推荐）
- Vuex（已逐步被 Pinia 替代）
- 组合式 API + 响应式服务（轻量级状态）
- 组件库：Element Plus、Ant Design Vue、Naive UI 等

## 决策

待定。推荐在 S1 门禁前确定目录结构、状态管理方案和组件库。

## 后果

- 影响 PC 端工程骨架和代码组织。
- 影响前后端接口调用方式。
