# ADR-009：uni-app 支持端范围

## 状态

proposed

## 上下文

移动端采用 uni-app + Vue3。需要明确支持哪些端（H5、小程序、App 等）。

## 考虑选项

- H5 + 微信小程序（最小范围）
- H5 + 微信小程序 + App（uni-app 三端）
- 仅 H5（降低复杂度）

## 决策

待定。推荐在 S1 门禁前确认支持端范围，以便确定构建和调试策略。

## 后果

- 影响移动端工程骨架和构建配置。
- 影响消息推送、文件上传等功能的实现。
