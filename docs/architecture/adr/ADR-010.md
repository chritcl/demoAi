# ADR-010：日志、审计和可观测性

## 状态

proposed

## 上下文

系统需要操作日志、审计日志和基本可观测性能力，以支持故障排查、安全审计和合规。

## 考虑选项

- Logback + 结构化日志（JSON）
- Micrometer + Prometheus（指标）
- OpenTelemetry（分布式追踪）
- 操作日志与业务审计分离存储

## 决策

待定。推荐在 S1 门禁前确定日志格式、审计日志存储和可观测性基础方案。

## 后果

- 影响 `s8_audit` 业务包的设计。
- 影响部署和运维方案。
