# WP-009：API、安全与非功能基线

## 目标

建立 API、安全、数据权限、非功能需求的统一基线，作为后端、PC、移动端实现的约束输入。

## 范围

- API 规范（REST、版本、错误码、分页）。
- 统一错误码体系。
- 身份安全（JWT、会话、刷新、吊销）。
- 数据权限（RBAC、数据范围、字段脱敏）。
- 文件安全（上传、下载、存储、访问控制）。
- 日志脱敏与审计要求。
- 性能目标（响应时间、并发）。
- 可用性目标（SLA、备份窗口）。
- 备份和审计要求。

## 不在范围

- 不实现具体安全过滤器或拦截器。
- 不部署真实基础设施。
- 不生成具体迁移脚本。

## 依赖

- WP-007：领域地图与业务包边界（done）
- WP-008：核心技术与架构 ADR（done）

## 风险

- 高：安全基线需要合规确认。
- 中：非功能目标可能与旧系统性能数据冲突。

## 验收标准

1. API 规范文档可指导后端和前端实现。
2. 错误码体系覆盖常见失败场景。
3. 安全基线覆盖身份、数据、文件、日志。
4. 非功能目标量化且可验证。
