# 路线图（ROADMAP）

本文件定义 demoAi 项目从 S0 到 S6 的演进路线图。

## 当前阶段

- **S0：仓库治理与执行底座**（进行中）
- 目标：建立可由 Codex 跨会话持续执行的工程体系。
- 门禁：G0（hybrid）

## S0 目标

1. 完成仓库审计与凭据风险处理（WP-000）。
2. 重建文档真源（WP-001）。
3. 建立 Codex 执行协议（WP-002）。
4. 定义架构边界与 ADR 待办（WP-003）。
5. 建立执行体系自动验证（WP-004）。
6. 通过 G0 门禁。

## S1 目标

1. 评审并批准所有 S0 提出的 ADR（ADR-001 至 ADR-010）。
2. 冻结技术版本基线。
3. 决定流程引擎选型。
4. 创建工程骨架（后端、PC 端、移动端）。
5. 引入架构自动验证（ArchUnit 等）。
6. 通过 G1 人工门禁。

## S2 目标

1. 后端可构建、可运行基础 API。
2. PC 端可构建、可运行基础页面。
3. 移动端（uni-app）可构建、可运行基础页面。
4. CI 通过基础构建和架构测试。
5. 通过 G2 自动门禁。

## S3 目标

1. 实现一期核心业务（具体范围由产品文档定义）。
2. 通过一期业务测试。
3. 通过 G3 人工门禁。

## S4 目标

1. 完善一期业务。
2. 集成测试通过。
3. 性能基准可接受。
4. 通过 G4 自动门禁。

## S5 目标

1. 实现二期业务扩展。
2. 回归测试通过。
3. 通过 G5 自动门禁。

## S6 目标

1. 系统验收。
2. 部署文档完整。
3. 用户签署交付。
4. 通过 G6 人工门禁。

## 三期能力

- 三期需求已在 `docs/product/GOAL.md` 中保留映射。
- 三期能力不得进入当前实施工作包。
- 三期将在 S6 后另行规划。

## 路线图维护

- 本文件由每个阶段首个工作包负责维护。
- 阶段升级后，更新本文件中的“当前阶段”。
- 路线图变更必须经过对应阶段人工门禁批准。
