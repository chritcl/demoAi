# 工作包模板

## 标识

| 字段 | 说明 |
|---|---|
| ID | 工作包唯一标识，例如 `WP-000` |
| 标题 | 一句话描述 |
| 所属 Stage | 例如 `S0` |
| 状态 | `draft` / `ready` / `in_progress` / `blocked` / `review` / `done` / `cancelled` |
| 优先级 | 数字越小优先级越高 |
| 风险等级 | `low` / `medium` / `high` / `critical` |
| 依赖工作包 | 依赖全部 `done` 后本包才能进入 `ready` |
| 阻塞工作包 | 被本包阻塞的工作包 |
