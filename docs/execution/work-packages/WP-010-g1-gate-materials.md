# WP-010：G1 门禁材料汇总

## 目标

汇总 S1 全部输入材料，检查 ADR 状态，生成 G1 人工评审材料，等待用户批准。

## 范围

- 汇总 WP-006 至 WP-009 的输出。
- 检查所有 S1 相关 ADR 状态是否为 accepted。
- 检查 DOMAIN-MAP.md、TRACEABILITY.md、DATA-ARCHITECTURE.md 是否一致。
- 生成 G1 人工评审材料清单。
- 明确 G1 已知风险。

## 不在范围

- 不自动批准 G1。
- 不创建工程骨架。
- 不开始 S2 工作。

## 依赖

- WP-006：需求基线与阶段映射（done）
- WP-007：领域地图与业务包边界（done）
- WP-008：核心技术与架构 ADR（done）
- WP-009：API、安全与非功能基线（done）

## 风险

- 高：G1 为人工门禁，必须等待用户明确批准。
- 中：材料不一致会导致 G1 评审失败。

## 验收标准

1. G1 评审材料完整且一致。
2. 所有依赖工作包均已完成。
3. 材料明确列出“待决策事项”和“已知风险”。
4. 不伪造批准状态。

## 证据

完成后在 `docs/execution/evidence/WP-010-g1-gate-materials.md` 中记录，并准备 G1 评审会议。
