# 运维体系

本文件定义 demoAi 项目的运维文档边界、当前状态与后续工作包。

当前阶段、活动门禁和工作包状态以 `docs/execution/STATE.json` 为唯一真源。

## 运维目标

- 提供可部署、可备份、可恢复、可回滚的交付物。
- 记录环境配置、凭据管理、日志与监控策略。
- 支持用户验收和上线发布。

## 当前状态

- S0 阶段完成仓库治理与执行底座。
- S1 阶段将冻结数据架构、安全基线、API 契约和非功能目标。
- 具体运维方案（部署、备份、监控、告警）将在 S6 发布准备阶段完成。

## 后续工作包

- WP-009：API、安全与非功能基线（定义性能、可用性、备份和审计要求）。
- S2 后由对应阶段工作包引入 CI/CD、环境配置和可观测性方案。
- S6 完成部署、备份恢复、发布回滚和运维文档。

## 风险

- 旧环境凭据和配置未完全脱敏，需用户确认是否已轮换或环境已下线。
- G0 证据已记录该风险，但无法自动验证外部状态。
