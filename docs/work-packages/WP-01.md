# WP-01 工程骨架与开发环境

## 基本信息

- **ID**: WP-01
- **标题**: 工程骨架与开发环境
- **所属阶段**: S1
- **状态**: draft

## 覆盖的 Excel 功能

本工作包为基础设施，不直接对应 Excel 功能行。

## 依赖

无

## 目标

建立后端、PC、uni-app 三个工程的骨架，配置 pnpm workspace，建立数据库迁移基础，配置 CI。

## 范围

1. 后端工程骨架
   - Maven 单工程结构
   - Spring Boot 基础配置
   - 业务包目录结构（s0_xtsz, s1_portal, s2_document, s3_office, s4_workflow, s5_contacts, s6_file, s7_message, s8_audit）
   - 每个业务包内部分层（controller, service, service.impl, mapper, entity, dto, vo）
   - Result<T> 统一返回
   - BusinessException 全局异常处理
   - ArchUnit 包边界测试

2. PC 工程骨架
   - Vue3 + TypeScript
   - Element Plus
   - 路由、状态管理、请求封装
   - 基础布局

3. uni-app 工程骨架
   - uni-app + Vue3
   - H5 构建配置
   - 基础页面

4. pnpm workspace
   - 根级 pnpm-workspace.yaml
   - 根级 pnpm-lock.yaml

5. 数据库迁移
   - Flyway 或等价方案
   - 基础表结构脚本

6. CI
   - GitHub Actions 或等价方案
   - 后端构建测试
   - PC 构建测试
   - uni-app H5 构建

## 不在范围

- 业务功能实现
- 旧代码迁移
- 生产环境配置

## 实施要求

1. 后端使用 Spring Boot 3.x + JDK 17+
2. PC 端使用 Vue3 + TypeScript + Element Plus
3. 移动端使用 uni-app + Vue3
4. 数据库使用 MySQL 8.x
5. 包管理使用 pnpm
6. 所有代码注释使用中文
7. 所有文件使用 UTF-8 without BOM

## 验收标准

1. 后端 `mvn clean test` 通过
2. PC 端 `pnpm build` 通过
3. uni-app H5 `pnpm build` 通过
4. ArchUnit 测试通过
5. 数据库迁移脚本可执行
6. CI 流水线通过

## 验证命令

```bash
# 后端
cd backend && mvn clean test

# PC
cd pc && pnpm install && pnpm build

# uni-app
cd mobile && pnpm install && pnpm build

# ArchUnit
cd backend && mvn test -Dtest=ArchUnitTests
```
