- WP-01

## 目标

实现统一身份认证、RBAC 权限管理、组织架构管理、成员管理、密码策略和文件设置。

## 范围

1. 身份认证
   - JWT 无状态认证
   - 登录/登出
   - 登录日志

2. 权限管理
   - 角色管理（CRUD）
   - 菜单管理（CRUD）
   - 用户角色关联
   - 角色菜单关联
   - 角色部门关联（数据范围）
   - RBAC + 数据范围鉴权

3. 组织架构
   - 部门管理（树形 CRUD）
   - Excel 批量导入
   - 部门检索

4. 成员管理
   - 用户管理（CRUD）
   - 批量操作
   - 用户角色关联

5. 密码策略
   - 密码复杂度规则
   - 登录失败锁定

6. 文件设置
   - 文件服务配置
   - 本地存储实现
   - 可扩展 OSS

7. 日志管理
   - 操作日志（@OperLog AOP）
   - 登录日志

## 不在范围

- SSO 单点登录
- 二维码登录
- 手势/指纹密码
- 自定义水印
- 禁止截屏
- 登录黑白名单
- 安全审计
- 版本设置

## 实施要求

1. 使用 RBAC 模型
2. 数据范围基于角色-部门关联
3. JWT 无状态认证
4. 密码使用 BCrypt 加密
5. 操作日志使用 AOP 实现

## 验收标准

1. 登录/登出正常
2. 角色 CRUD 正常
3. 菜单 CRUD 正常
4. 部门树形管理正常
5. 用户 CRUD 正常
6. 权限鉴权正常
7. 数据范围过滤正常
8. 密码策略生效
9. 操作日志记录正常
10. 所有测试通过
