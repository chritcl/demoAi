# WP-02 身份、权限、组织与成员

## 目标

实现一期统一身份认证、RBAC 权限管理、组织架构管理、成员管理和密码策略。

## 范围

1. 身份认证：JWT 无状态认证、登录和登出。
2. 权限管理：角色和菜单 CRUD、用户角色关联、角色菜单关联、角色部门关联、RBAC 与数据范围鉴权。
3. 组织架构：部门树形 CRUD、Excel 批量导入和部门检索。
4. 成员管理：用户 CRUD、批量操作和用户角色关联。
5. 密码策略：密码复杂度规则、登录失败锁定和 BCrypt 密码加密。

## 依赖

- WP-01。

## 不在范围

- 文件设置、操作日志和登录日志实现（WP-04）。
- SSO 单点登录、二维码登录、手势/指纹密码、自定义水印、禁止截屏、登录黑白名单、安全审计和版本设置。

## 验收标准

1. 登录、登出、角色和菜单 CRUD 正常。
2. 部门树形管理、用户 CRUD 和批量操作正常。
3. 权限鉴权和数据范围过滤正常。
4. 密码策略生效。
5. 所有测试通过。
