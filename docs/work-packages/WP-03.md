# WP-03 流程基础能力

## 目标

实现一期流程引擎基础能力，支持流程定义、流程实例、任务管理、退办、撤办、催办、转办和发文所需的最小并行会签能力。

## 范围

1. 流程定义：流程定义 CRUD、流程节点配置、节点操作权限和节点办理人员。
2. 流程实例：流程发起、审批、完结和撤回。
3. 任务管理：待办、已办和办结任务。
4. 流程操作：退办、催办和转办；流程定义使用 JSON 配置并保留清晰任务状态机与委托授权扩展边界。
5. 发文会签最小能力：创建和查询会签任务，配置和执行并行会签节点，汇聚每位会签人员的结果，以全部人员通过为会签通过条件，并记录办理时间和意见审计。
6. 向 WP-07 公开 CountersignWorkflowService：输入为流程实例、会签节点、会签人员、发起人或会签办理结果；输出为会签任务及待办列表、结果汇聚状态和通过条件；人员为空、节点或任务不存在、任务不可办理、非受理人员办理或重复办理时抛出业务异常。WP-03 拥有流程、任务和会签审计数据，WP-07 只保存引用且不得直接读写这些数据表。

## 依赖

- WP-02。

## 不在范围

- 除发文固定并行会签节点外的复杂会签编排。
- 通用复杂 BPMN 编排、任意并行网关设计器、完整流程建模平台、条件网关、子流程和流程版本管理。

## 验收标准

1. 流程定义 CRUD、流程发起、审批、完结和撤回正常。
2. 待办、已办、办结查询及退办、催办、转办正常。
3. 会签任务、并行会签节点、结果汇聚、通过条件及审计正常。
4. 所有测试通过。
