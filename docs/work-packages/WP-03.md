## 依赖

- WP-02

## 目标

实现流程引擎基础能力，支持流程定义、流程实例、任务管理、退办、撤办、催办、转办。

## 范围

1. 流程定义
   - 流程定义管理（CRUD）
   - 流程节点配置
   - 节点操作权限
   - 节点办理人员

2. 流程实例
   - 流程发起
   - 流程审批
   - 流程完结
   - 流程撤回

3. 任务管理
   - 待办任务
   - 已办任务
   - 办结任务

4. 流程操作
   - 退办
   - 催办
   - 转办

5. 发文会签最小能力
   - 创建并查询会签任务
   - 配置并执行并行会签节点
   - 汇聚每位会签人员的办理结果
   - 以全部会签人员均通过作为会签通过条件
   - 会签人员和结果审计，记录办理时间和意见

## 跨业务包公开 Service 声明

### CountersignWorkflowService

- **调用方**：WP-07（`s2_document`）发文流程。
- **输入**：发文流程实例标识、会签节点标识、会签人员列表、发起人标识；以及会签任务标识、办理人标识、通过或不通过结果和意见。
- **输出**：会签任务标识及其待办列表；会签结果汇聚状态、各人员结果和是否满足会签通过条件。
- **错误语义**：会签人员为空、节点或任务不存在、任务不处于可办理状态、非受理人员办理、重复办理时抛出业务异常；不以成功结果包装失败状态。
- **数据所有权边界**：WP-03 拥有流程定义、流程实例、会签节点、会签任务和会签审计数据；WP-07 仅拥有公文业务数据，并保存流程实例或会签任务的引用，不直接读写 WP-03 的数据表。

## 不在范围

- 除发文所需的固定并行会签节点之外的复杂会签编排
- 通用复杂 BPMN 编排
- 任意并行网关设计器
- 完整流程建模平台
- 条件网关
- 子流程
- 流程版本管理

## 实施要求

1. 流程引擎可选 Activiti/Flowable/自研轻量方案
2. 流程定义支持 JSON 配置
3. 任务状态机清晰
4. 支持委托授权扩展
5. 会签只实现本工作包定义的最小能力，不扩展为通用流程建模能力

## 验收标准

1. 流程定义 CRUD 正常
2. 流程发起、审批、完结正常
3. 待办、已办、办结查询正常
4. 退办、催办、转办正常
5. 会签任务、并行会签节点、结果汇聚、通过条件和会签人员及结果审计正常
6. 所有测试通过
