## 目标

实现流程引擎基础能力，支持流程定义、流程实例、任务管理、退办、撤办、催办、转办。

## 范围

1. 流程定义
   - 流程定义管理（CRUD）
   - 流程节点配置
   - 节点操作权限
   - 节点办理人员

2. 流程实例
   - 流程发起
   - 流程审批
   - 流程完结
   - 流程撤回

3. 任务管理
   - 待办任务
   - 已办任务
   - 办结任务

4. 流程操作
   - 退办
   - 催办
   - 转办

## 不在范围

- 复杂会签
- 并行网关
- 条件网关
- 子流程
- 流程版本管理

## 实施要求

1. 流程引擎可选 Activiti/Flowable/自研轻量方案
2. 流程定义支持 JSON 配置
3. 任务状态机清晰
4. 支持委托授权扩展

## 验收标准

1. 流程定义 CRUD 正常
2. 流程发起、审批、完结正常
3. 待办、已办、办结查询正常
4. 退办、催办、转办正常
5. 所有测试通过
