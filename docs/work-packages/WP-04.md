# WP-04 文件、消息与审计基础

## 目标

实现一期文件服务、消息服务和审计日志公共基础能力。

## 范围

1. 文件服务：上传、下载、本地存储、可扩展 OSS 和文件配置管理。
2. 消息服务：站内消息、消息模板、发送与接收，以及 WebSocket 或轮询。
3. 审计日志：使用 AOP 的操作日志、登录日志和日志查询。

## 依赖

- WP-02。

## 不在范围

- 安全审计（二期）。
- 版本管理（三期）。

## 验收标准

1. 文件上传、下载和文件配置管理正常。
2. 消息发送和接收正常。
3. 操作日志和登录日志记录正常。
4. 所有测试通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
```
