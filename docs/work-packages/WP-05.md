# WP-05 门户、工作台与通讯录

## 目标

实现一期门户首页、工作台、通讯录及移动端基础能力的后端、PC 和 uni-app H5 功能。

## 范围

1. 门户首页：主题和主页设计、统计卡片、最近公告、待办列表、快捷导航和消息提醒。
2. 工作台：个人信息查看和修改、密码修改、待办、已办、办结、流程起草、我的草稿和我的发起。
3. 通讯录：树状展示、排序及姓名精确、模糊和拼音搜索。
4. 后端 API：门户数据聚合、工作台数据和通讯录查询接口。
5. PC 页面：门户首页、工作台和通讯录。
6. uni-app H5 页面：门户首页、工作台、通讯录及移动端基础能力所需入口；复用后端 API。

## 依赖

- WP-02。
- WP-03。
- WP-04。

## 不在范围

- 领导门户、组织节点保护和委托授权（WP-11）。

## 验收标准

1. 门户首页和消息提醒正常。
2. 工作台各功能正常。
3. 通讯录展示、排序和拼音搜索正常。
4. PC 与 H5 构建通过，所有测试通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
