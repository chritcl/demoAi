## 目标

实现门户首页、工作台、通讯录的后端、PC 和 uni-app H5 功能。

## 范围

1. 门户首页
   - 主题/主页设计
   - 统计卡片
   - 最近公告
   - 待办列表
   - 快捷导航
   - 消息提醒

2. 工作台
   - 个人信息查看/修改
   - 密码修改
   - 待办事项
   - 已办事项
   - 办结事项
   - 流程起草
   - 我的草稿
   - 我的发起

3. 通讯录
   - 树状展示
   - 排序
   - 搜索（姓名精确/模糊/拼音）

4. 后端 API
   - 门户数据聚合接口
   - 工作台数据接口
   - 通讯录查询接口

5. PC 端页面
   - 门户首页
   - 工作台
   - 通讯录

6. uni-app H5 页面
   - 门户首页
   - 工作台
   - 通讯录
   - 移动端基础能力所需的首页、工作台和通讯录基础入口

## 不在范围

- 领导门户（WP-11）
- 组织节点保护（WP-11）
- 委托授权（WP-11）

## 实施要求

1. 门户首页使用卡片布局
2. 通讯录支持拼音搜索（pinyin4j）
3. 待办/已办/办结与流程引擎集成
4. H5 端复用后端 API

## 验收标准

1. 门户首页正常显示
2. 消息提醒正常
3. 工作台各功能正常
4. 通讯录展示、排序、搜索正常
5. PC 构建通过
6. H5 构建通过
7. 所有测试通过

## 验证命令

```bash
# 后端测试
cd backend && mvn test

# PC 构建
cd pc && pnpm build

# H5 构建
cd mobile && pnpm build:h5
```
