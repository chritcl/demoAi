# WP-06 信息发布与通知公告

## 基本信息

- **ID**: WP-06
- **标题**: 信息发布与通知公告
- **所属阶段**: S2

## 覆盖的 Excel 功能

| 序号 | 一级功能 | 二级功能 | 阶段 |
|------|----------|----------|------|
| 2 | 信息发布 | 信息发布 | 一期 |
| 3 | 通知公告 | 通知公告 | 一期 |

## 依赖

- WP-03
- WP-04
- WP-05

## 目标

实现信息发布和通知公告的后端、PC 和 uni-app H5 功能。

## 范围

1. 信息发布
   - 文章发布（含审核流程）
   - 栏目管理
   - 下载次数统计
   - 人员/置顶/查看权限/阅读时效
   - 文章附件

2. 通知公告
   - 公告发布/撤回/置顶
   - 阅读统计（按人去重）
   - 公告查询

3. 后端 API
   - 信息发布接口
   - 通知公告接口

4. PC 端页面
   - 信息发布管理
   - 通知公告管理
   - 信息发布查看
   - 通知公告查看

5. uni-app H5 页面
   - 信息发布查看
   - 通知公告查看

## 不在范围

- 公文管理（WP-07）

## 实施要求

1. 信息发布含审核流程
2. 通知公告阅读统计按人去重
3. 支持 PC 和移动端查看

## 验收标准

1. 文章发布、审核、查看正常
2. 栏目管理正常
3. 公告发布、撤回、置顶正常
4. 阅读统计正常
5. PC 构建通过
6. H5 构建通过
7. 所有测试通过

## 验证命令

```bash
# 后端测试
cd backend && mvn test

# PC 构建
cd pc && pnpm build

# H5 构建
cd mobile && pnpm build:h5
```
