# WP-06 信息发布与通知公告

## 目标

实现一期信息发布和通知公告的后端、PC 和 uni-app H5 功能。

## 范围

1. 信息发布：含审核流程的文章发布、栏目管理、下载次数统计、人员、置顶、查看权限、阅读时效和文章附件。
2. 通知公告：公告发布、撤回、置顶、按人去重的阅读统计和公告查询。
3. 后端 API：信息发布和通知公告接口。
4. PC 页面：信息发布管理、通知公告管理及对应查看页面。
5. uni-app H5 页面：信息发布和通知公告查看页面。

## 依赖

- WP-03。
- WP-04。
- WP-05。

## 不在范围

- 公文管理（WP-07）。

## 验收标准

1. 文章发布、审核、查看和栏目管理正常。
2. 公告发布、撤回、置顶、查询和阅读统计正常。
3. PC 与 H5 构建通过，所有测试通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
