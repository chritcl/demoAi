# WP-07 公文管理

## 目标

实现一期发文管理、收文管理、文号管理和公文查询的后端、PC 和 uni-app H5 功能。

## 范围

1. 发文管理：模板、拟稿、审核、复审、会签、批示、校对、签发、核发文号、盖章、传阅和发文。
2. 发文会签通过 WP-03 的 CountersignWorkflowService 创建会签任务、执行并行会签节点、获取结果汇聚和通过条件，并展示会签人员与结果审计；仅维护公文和流程引用，不直接访问 WP-03 的流程、任务或审计数据。
3. 收文管理：来文登记、传递、审批、发送、催办、归档和收文流程。
4. 文号管理：文种、年度流水号和文号生成规则。
5. 公文查询：多条件查询和数据权限过滤。
6. 后端 API、PC 页面及 uni-app H5 公文查看和审批页面。

## 依赖

- WP-03。
- WP-04。
- WP-05。

## 不在范围

- 公文交换（三期）。
- 意见用语和公文统计（WP-11）。
- 在公文业务包中重建流程引擎、会签任务、并行节点或会签审计。

## 验收标准

1. 发文和收文流程完整正常。
2. 文号自动生成和公文查询正常。
3. 会签集成、结果汇聚和审计展示正常。
4. PC 与 H5 构建通过，所有测试通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
