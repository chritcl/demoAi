## 目标

实现发文管理、收文管理、文号管理和公文查询的后端、PC 和 uni-app H5 功能。

## 范围

1. 发文管理
   - 发文模板管理
   - 拟稿/审核/复审/会签/批示/校对/签发/核发文号/盖章/传阅/发文
   - 调用 WP-03 的 `CountersignWorkflowService` 创建会签任务、执行并行会签节点、获取会签结果汇聚和会签通过条件
   - 发文流程与会签人员和结果审计展示

2. 收文管理
   - 来文登记
   - 传递/审批/发送/催办/归档
   - 收文流程

3. 文号管理
   - 文种管理
   - 年度流水号
   - 文号生成规则

4. 公文查询
   - 多条件查询
   - 数据权限过滤

5. 后端 API
   - 发文管理接口
   - 收文管理接口
   - 文号管理接口
   - 公文查询接口

6. PC 端页面
   - 发文管理
   - 收文管理
   - 文号管理
   - 公文查询

7. uni-app H5 页面
   - 公文查看
   - 公文审批

## 流程依赖声明

- **依赖工作包与接口**：WP-03 的 `CountersignWorkflowService`。
- **调用目的**：发文流程在会签环节创建会签任务，驱动并行会签节点，并读取会签结果汇聚及会签通过条件。
- **输入**：发文流程实例标识、会签节点标识、会签人员列表、发起人标识；会签办理时传递任务标识、办理人标识、结果和意见。
- **输出**：会签任务待办列表、人员办理结果、汇聚状态和是否通过。
- **错误处理与数据边界**：透传 WP-03 定义的业务异常；WP-07 仅维护公文及流程引用，不直接访问 WP-03 的流程、任务和审计数据。

## 不在范围

- 公文交换（三期）
- 意见用语（WP-11）
- 公文统计（WP-11）
- 在公文业务包中自行实现另一套流程引擎、会签任务、并行节点或会签审计

1. 发文流程通过 WP-03 的 `CountersignWorkflowService` 使用会签任务、并行会签节点、结果汇聚、通过条件和会签人员及结果审计
2. 收文流程完整电子化
3. 文号自动生成
4. 公文查询支持数据权限
