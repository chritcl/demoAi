# WP-08 综合办公一期

## 目标

实现一期用车、用印、出差和请休假流程的后端、PC 和 uni-app H5 功能。

## 范围

1. 用车：车辆管理、用车申请、审批、车辆状态管理和汇总分析。
2. 用印：用印申请、审批和用印登记。
3. 出差：出差申请、审批和出差记录。
4. 请休假：可自定义假别、请假申请、审批和请假记录。
5. 以上流程与流程引擎集成，并提供后端 API、PC 管理页面和 H5 申请页面。

## 依赖

- WP-03。
- WP-04。
- WP-05。

## 不在范围

- 资产管理、智慧考勤和办公用品管理（WP-10）。

## 验收标准

1. 用车、用印、出差和请休假流程完整正常。
2. 假别自定义正常。
3. PC 与 H5 构建通过，所有测试通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
