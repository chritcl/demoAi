# WP-08 综合办公一期

## 基本信息

- **ID**: WP-08
- **标题**: 综合办公一期
- **所属阶段**: S2

## 覆盖的 Excel 功能

| 序号 | 一级功能 | 二级功能 | 阶段 |
|------|----------|----------|------|
| 6 | 综合办公 | 用车流程 | 一期 |
| 6 | 综合办公 | 用印流程 | 一期 |
| 6 | 综合办公 | 出差管理 | 一期 |
| 6 | 综合办公 | 请休假管理 | 一期 |

## 依赖

- WP-03
- WP-04
- WP-05

## 目标

实现用车、用印、出差、请休假等综合办公流程的后端、PC 和 uni-app H5 功能。

## 范围

1. 用车流程
   - 车辆管理
   - 用车申请
   - 审批流程
   - 车辆状态管理
   - 汇总分析

2. 用印流程
   - 用印申请
   - 审批流程
   - 用印登记

3. 出差管理
   - 出差申请
   - 审批流程
   - 出差记录

4. 请休假管理
   - 假别管理（含自定义）
   - 请假申请
   - 审批流程
   - 请假记录

5. 后端 API
   - 用车流程接口
   - 用印流程接口
   - 出差管理接口
   - 请休假管理接口

6. PC 端页面
   - 用车管理
   - 用印管理
   - 出差管理
   - 请休假管理

7. uni-app H5 页面
   - 用车申请
   - 用印申请
   - 出差申请
   - 请假申请

## 不在范围

- 资产管理（WP-10）
- 智慧考勤（WP-10）
- 办公用品管理（WP-10）

## 实施要求

1. 所有流程与流程引擎集成
2. 支持 PC 和移动端
3. 假别支持自定义

## 验收标准

1. 用车流程完整正常
2. 用印流程完整正常
3. 出差流程完整正常
4. 请休假流程完整正常
5. PC 构建通过
6. H5 构建通过
7. 所有测试通过

## 验证命令

```bash
# 后端测试
cd backend && mvn test

# PC 构建
cd pc && pnpm build

# H5 构建
cd mobile && pnpm build:h5
```
