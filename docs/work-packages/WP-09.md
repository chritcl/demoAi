# WP-09 一期集成验证与 G2 准备

## 基本信息

- **ID**: WP-09
- **标题**: 一期集成验证与 G2 准备
- **所属阶段**: S2

## 覆盖的 Excel 功能

本工作包为集成验证类，不直接对应 Excel 功能行。覆盖全量一期功能的端到端验证。

## 依赖

- WP-05
- WP-06
- WP-07
- WP-08

## 目标

完成一期 PC 与 H5 联调、端到端测试、需求覆盖检查、全量构建，为 G2 门禁准备条件。

## 范围

1. 一期 PC 与 H5 联调
   - 后端 API 联调
   - PC 端功能联调
   - H5 端功能联调

2. 一期端到端测试
   - 门户、工作台、通讯录端到端
   - 信息发布、通知公告端到端
   - 公文管理端到端
   - 综合办公端到端

3. 一期需求覆盖检查
   - 对照 Excel 一期功能清单逐项确认
   - 标记已覆盖和未覆盖项

4. 全量构建
   - 后端全量构建测试
   - PC 端全量构建
   - H5 端全量构建

5. G2 自动条件验证
   - 一期工作包全部 done
   - 一期需求全部覆盖
   - 自动化测试通过
   - PC 与 H5 构建通过

## 不在范围

- 二期功能
- 消息提醒开发（WP-05 已完成）
- 公告开发（WP-06 已完成）
- 流程审批开发（WP-03/WP-07/WP-08 已完成）
- 文件查询开发（WP-04 已完成）
- 通讯录开发（WP-05 已完成）
- 个人设置开发（WP-05 已完成）

## 实施要求

1. 联调覆盖一期全部功能
2. 端到端测试覆盖主要业务流程
3. 需求覆盖检查逐项确认
4. 全量构建无错误

## 验收标准

1. 一期 PC 与 H5 联调通过
2. 端到端测试通过
3. 需求覆盖检查完成
4. 全量构建通过
5. G2 自动条件全部满足

## 验证命令

```bash
# 后端全量测试
cd backend && mvn test

# PC 构建
cd pc && pnpm build

# H5 构建
cd mobile && pnpm build:h5
```
