# WP-09 一期集成验证

## 目标

完成一期 PC 与 H5 联调、端到端测试、需求覆盖检查和全量本地构建，为一期阶段验收准备可验证结果。

## 范围

1. 一期 PC、H5 与后端 API 联调。
2. 门户、工作台、通讯录、信息发布、通知公告、公文管理和综合办公的端到端测试。
3. 对照功能开发清单逐项确认一期功能覆盖。
4. 后端全量测试、PC 全量构建和 H5 全量构建。

## 依赖

- WP-05。
- WP-06。
- WP-07。
- WP-08。

## 不在范围

- 二期功能。
- 重复实现消息提醒、公告、流程审批、文件查询、通讯录或个人设置功能。

## 验收标准

1. 一期 PC 与 H5 联调和端到端测试通过。
2. 一期需求覆盖检查完成。
3. 后端测试、PC 构建和 H5 构建通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
