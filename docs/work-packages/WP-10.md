# WP-10 二期资产、办公用品与考勤

## 目标

实现二期资产管理、智慧考勤和办公用品管理功能。

## 范围

1. 资产管理：资产申请、领用、调拨、减损、报废、汇总统计、全生命周期管理和审批流程。
2. 智慧考勤：考勤规则、加班、出差、公出规则、班次、节假日、报表自定义及考勤流程关联。
3. 办公用品：库存、出入库记录、申请、申请记录和审批流程。
4. 提供对应后端、PC 与 H5 能力。

## 依赖

- WP-03。
- WP-08。

## 不在范围

- 一期综合办公功能（WP-08）。

## 验收标准

1. 资产全生命周期、考勤规则和办公用品管理正常。
2. 相关审批流程正常。
3. PC 与 H5 构建通过，所有测试通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
