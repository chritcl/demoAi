# WP-10 二期资产、办公用品与考勤

## 基本信息

- **ID**: WP-10
- **标题**: 二期资产、办公用品与考勤
- **所属阶段**: S3

## 依赖

- WP-03
- WP-08

## 目标

实现资产管理、智慧考勤、办公用品管理等二期综合办公功能。

## 范围

1. 资产管理
   - 资产申请/领用/调拨/减损/报废
   - 汇总统计
   - 全生命周期管理
   - 审批流程

2. 智慧考勤
   - 考勤规则配置
   - 加班/出差/公出规则
   - 班次管理
   - 节假日管理
   - 报表自定义
   - 与考勤流程关联

3. 办公用品管理
   - 库存管理
   - 出入库记录
   - 申请/申请记录
   - 审批流程

## 不在范围

- 一期综合办公功能（WP-08）

## 实施要求

1. 资产管理含审批流程
2. 考勤支持规则引擎
3. 办公用品含审批流程

## 验收标准

1. 资产管理全生命周期正常
2. 考勤规则配置正常
3. 办公用品管理正常
4. 所有流程正常
5. PC 构建通过
6. 所有测试通过

## 验证命令

```bash
# 后端测试
cd backend && mvn test

# PC 构建
cd pc && pnpm build

# H5 构建
cd mobile && pnpm build:h5
```
