# WP-11 二期增强功能

## 目标

实现二期门户、公文、通讯录、工作台和安全增强功能。

## 范围

1. 门户增强：统一认证接入协议、外部身份映射、令牌交换、模拟适配器和可替换的 SSO、短信、二维码登录适配器边界；应用中心、统一待办、拼音和全文检索、领导门户。
2. 公文增强：个人和公共意见用语库，以及收文、发文、签报统计与 Excel 导出。
3. 通讯录增强：角色至部门可见范围的组织节点保护。
4. 工作台增强：按流程类型和时间段的委托授权。
5. 安全增强：登录黑白名单和多维度留痕的安全审计。
6. 模拟适配器只用于自动验收，不得描述为已完成真实生产集成。

## 依赖

- WP-05。
- WP-06。
- WP-07。
- WP-08。

## 不在范围

- 一期和三期功能。
- 真实第三方 SSO、短信和二维码平台对接。

## 验收标准

1. 统一认证协议、外部身份映射、令牌交换和模拟适配器正常，且适配器可替换。
2. 应用中心、统一待办、统一搜索、领导门户、意见用语、公文统计、组织节点保护和委托授权正常。
3. 登录黑白名单和安全审计正常。
4. PC 与 H5 构建通过，所有测试通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
