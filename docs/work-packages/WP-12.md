# WP-12 集成测试、部署与发布

## 目标

完成一期和二期的全量集成测试、安全检查、性能验证、部署文档、发布回滚方案、用户文档和运维文档。

## 范围

1. 集成测试：全量回归、端到端测试和接口联调。
2. 安全检查：依赖漏洞、接口安全和敏感信息检查。
3. 性能验证：基础性能测试和数据库索引优化。
4. 交付文档：环境要求、部署步骤、配置说明、发布流程、回滚方案、备份恢复、用户手册、操作指南、运维手册和监控告警。

## 依赖

- WP-09。
- WP-10。
- WP-11。

## 不在范围

- 生产环境实际部署。
- 旧数据迁移。

## 验收标准

1. 一期和二期全量测试通过。
2. 安全检查通过，性能基线达标。
3. 部署、发布回滚、用户和运维文档完整。
4. 所有构建通过。

## 本地验证命令

```bash
cd backend && mvn test
cd pc && pnpm build
cd mobile && pnpm build:h5
```
