# 后端技术栈约束（oa-backend）

> 适用模块：`oa-backend/`（Spring Boot 3 单体后端，端口 10001）
> 本文件是后端开发的强制约束，新增/升级依赖、变更架构须先评审。

## 一、技术栈锁定（版本基线）

| 分类 | 技术 | 版本 | 说明 |
|---|---|---|---|
| 语言/运行时 | JDK | **17**（LTS） | 不允许降级 8/11，不主动升 21（除非评审） |
| 构建 | Maven | 3.8+ | `spring-boot-starter-parent` 统一管理 |
| 框架 | Spring Boot | **3.2.5** | 通过 parent 锁定 |
| 安全 | Spring Security | 6.x（随 Boot） | JWT 无状态 |
| ORM | MyBatis-Plus | **3.5.5** | `mybatis-plus-spring-boot3-starter` |
| 数据库 | MySQL | **8.x** | utf8mb4 |

| API 文档 | Knife4j | 4.4.0 | `knife4j-openapi3-jakarta` |

## 二、包结构与分层约束

```
com.oa.platform
├── common/        通用：annotation/aspect/constant/entity/enums/exception/page/util/api
├── config/        配置类（Security/Redis/MyBatis/Knife4j/跨域 等）
├── security/      认证授权（JWT 过滤器、UserDetailsService、登录登出）
├── system/        支撑平台（用户/角色/菜单/部门/字典/日志/文件/安全策略）
├── portal/        统一门户（公告、信息发布）
├── document/      公文管理（发文/收文/文号/交换）
├── office/        综合办公（请假/用车/用印/出差/资产/用品/考勤）
├── contacts/      通讯录
├── workflow/      流程引擎（定义/节点/实例/任务/事件）
└── file/          文件服务
```

### 分层（每个业务包内严格遵循）

```
controller/   仅做参数接收、校验、调用 service、组装 R<T>；禁止写业务逻辑
service/      业务逻辑；接口 + impl
mapper/       MyBatis-Plus Mapper，复杂查询写 XML
entity/       数据库实体（@TableName）
dto/          入参对象（请求）
vo/           出参对象（响应）
```

> 禁止 controller 直接调 mapper；禁止 service 返回 entity 给前端（必须转 vo）。

## 三、编码规范

### 3.1 统一响应

```java
// 所有接口统一返回 R<T>
public class R<T> { Integer code; String msg; T data; }
// 成功 R.ok(data)；失败 R.fail(msg)
```

- 全局异常处理：`@RestControllerAdvice` 的 `GlobalExceptionHandler` 拦截 `BusinessException`、`MethodArgumentNotValidException`、其他 `Exception`，统一转 `R.fail`。
- 业务异常用 `throw new BusinessException("错误描述")`，**禁止**用 `return R.fail` 混杂抛异常两种风格。

### 3.2 分页

- 入参继承 `PageQuery`（含 pageNum/pageSize），出参用 `PageResult<T>`。
- 禁止手写 limit 拼接，统一用 MyBatis-Plus `Page` + `IPage`。

### 3.3 实体与字段

- 实体继承统一基类（含 create_time/create_by/update_time/update_by/deleted/remark）。
- 逻辑删除：`@TableLogic`，`deleted` 字段 0 未删/1 已删；**禁止**物理删除业务数据。
- 自动填充：`@TableField(fill = FieldFill.INSERT/INSERT_UPDATE)` 由 `MetaObjectHandler` 填充 create_by/update_by/time。

### 3.4 命名

| 对象 | 规范 | 示例 |
|---|---|---|
| 类 | 大驼峰 | `OfficeLeaveServiceImpl` |
| 方法/变量 | 小驼峰 | `submitLeave` |
| 常量 | 全大写下划线 | `MAX_FILE_SIZE` |
| 数据库表/字段 | 蛇形小写 | `office_leave` / `leave_type` |
| URL | 蛇形/RESTful，模块前缀 | `/office/leave`、`/office/leave/{id}` |
| 权限标识 | 模块:资源:动作 | `office:leave:submit` |

### 3.5 操作日志

- 写操作（增删改）加 `@OperLog(businessType = BusinessType.INSERT/UPDATE/DELETE)`，AOP 异步记录到 `sys_oper_log`。

## 四、安全约束（红线）

1. **密码**：必须 BCrypt 加密存储，禁止明文/MD5。
2. **SQL 注入**：禁止拼接 SQL；MyBatis 用 `#{}`，动态排序/字段名用白名单校验后才可用 `${}`。
3. **鉴权**：除 `/auth/**`、`/captcha`、`/doc.html` 等白名单外，所有接口必须经 JWT 过滤器鉴权。
4. **越权**：列表/详情查询必须叠加数据权限（`data_scope`：全部/本部门/本部门及以下/仅本人/自定义）。
5. **文件上传**：校验类型/大小（`sys_file_config`），禁止上传可执行脚本；文件名重命名存储。
6. **敏感配置**：数据库/Redis 密码、JWT 密钥不硬编码，走 `application.yml` + 环境变量/外部配置。

## 五、事务与性能

1. **事务**：写多表/多步业务用 `@Transactional(rollbackFor = Exception.class)`；只读方法不加事务。
2. **大事务**：事务内**禁止**远程调用、文件 IO、循环单条 DB 操作（改批量）。
3. **缓存**：高频只读数据（字典、菜单、组织树）走 Redis；变更后主动失效。
4. **分页**：列表必须分页，禁止全表 `selectList` 返回前端。
5. **索引**：`docs/建库/oa_platform_full.sql` 中已建常用索引；新增查询字段需评估加索引，禁止 `like '%xx%'` 走全表。

## 六、流程引擎约束

- 业务（公文/请假/用车/用印/出差/资产/用品）**不得直接修改** `flow_*` 表，统一调用 `FlowService`。
- 流程办结通过 `FlowCompletedEvent` 解耦回写业务状态，监听器按 `business_type` 分发。
- 转办基于 `flow_delegation`；待办办理人解析按 `approver_type`（user/role/dept_leader/initiator）。

## 七、API 文档与测试

- 所有 controller 方法用 Knife4j 注解（`@Operation`/`@Parameter`），`/doc.html` 可见。
- 默认账号：admin/admin123、zhangsan/123456、lisi/123456。
- 单元测试用 JUnit5；Service 核心逻辑需有测试；构建 `mvn clean package -DskipTests` 必须通过。

## 八、禁止项（红线清单）

- ❌ 降级 JDK / 换框架（Struts、JSP）
- ❌ 引入重量级 BPM（Activiti/Flowable）—— 本系统用自研轻量引擎
- ❌ 物理删除业务数据（一律逻辑删除）
- ❌ controller 写业务逻辑 / 直连 mapper
- ❌ SQL 拼接、明文密码、硬编码密钥
- ❌ 引入未在 pom 声明的第三方 jar
- ❌ 大事务内做远程/IO 操作
