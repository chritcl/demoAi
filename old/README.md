# old/ 遗留参考区

本目录存放旧系统的源码、配置、脚本和参考材料，仅用于理解旧字段、业务关系、用户操作流程和历史需求。

## 重要声明

- 该目录是遗留参考区，不属于新系统默认构建、测试、启动和发布范围。
- 禁止把 `old/` 中的代码直接复制成新实现。
- 禁止让新代码依赖 `old/`。
- 旧配置、旧 SQL、旧实体和旧流程实现均不是新系统真源。
- 旧代码中的硬编码凭据已进行脱敏处理，但 Git 历史仍可能保留原值；使用旧配置前请确认对应环境已撤销或轮换。

## 允许操作

- 查看字段含义、字典值、历史业务流程、页面交互、表关系、用户角色和权限需求。
- 提取需要重新验证的业务规则。
- 对已跟踪文本文件执行凭据脱敏。
- 删除已提交的生成产物（target/、dist/、node_modules/、*.class、*.jar 等）。

## 禁止操作

- 新代码引用 `old/`。
- 复制整个旧类、旧页面或旧 SQL。
- 沿用旧包结构作为新架构。
- 直接沿用旧数据库主键和状态码。
- 沿用旧真实地址、账号、密码和密钥。
- 把旧代码能运行作为新工作包完成证据。
- 修改旧代码来实现新功能。
